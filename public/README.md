# Task Manager CRUD App

## Description

This project is a Task Manager CRUD application built using Express.js.
Users can create, read, update, and delete tasks.

## Features

- View all tasks
- Add new task
- Update task
- Delete task

## Technologies

- Node.js
- Express.js
- HTML
- CSS
- JavaScript

## Installation

```bash
npm install
```

## Run Project

```bash
node server.js
```

Open:

```
http://localhost:3000
```
